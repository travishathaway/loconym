# loconym logo – attribution

The loconym logo is a derivative mashup of two open source emoji artworks:

- **Magnifying glass** – Twemoji (https://github.com/twitter/twemoji), Copyright Twitter, Inc and other contributors.
  Graphics licensed under CC-BY 4.0 (https://creativecommons.org/licenses/by/4.0/); code under MIT.
- **Crocodile** – Noto Emoji (https://github.com/googlefonts/noto-emoji), Copyright Google Inc.,
  licensed under the Apache License 2.0 (see NOTO-LICENSE-APACHE-2.0.txt).

The full-detail logos (large, medium) reuse the original artwork, modified and combined
(magnifying glass with its handle tucked behind the crocodile). The small (favicon) version
is a simplified redrawing inspired by those shapes and colors.

The wordmark in the large logo is "loconym" set in Space Mono Bold (https://github.com/googlefonts/spacemono),
Copyright 2016 The Space Mono Project Authors, licensed under the SIL Open Font License 1.1
(see ../fonts/OFL.txt), converted to outlines.
